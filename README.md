# LongBets

ASP.NET MVC 5-projekt (.NET Framework 4.8) baseret på HTML-temaet "Scalar" fra Pixelarity.

## Indhold

- `Controllers/`, `Views/`, `App_Start/` – MVC-delen
- `px-scalar-html/` – HTML-mockups i tre farvevarianter (green, orange, red)
- `px-scalar-psd/` – PSD-mockups

## Udvikling

Åbn `LongBets.csproj` i Visual Studio, gendan NuGet-pakker og kør projektet (IIS Express).
